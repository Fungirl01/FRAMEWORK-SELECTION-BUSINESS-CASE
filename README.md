# FRAMEWORK SELECTION & BUSINESS CASE

This repository contains the recommended security framework and supporting artifacts for Maple Health Connect.

Files:

- [BUSINESS_CASE_NIST_CSF.md](./BUSINESS_CASE_NIST_CSF.md) — Executive business case recommending adoption of the NIST Cybersecurity Framework (CSF), mapped to Canadian privacy requirements (PIPEDA and Quebec Law 25).
- [NIST_to_PIPEDA_Law25_Mapping.csv](./NIST_to_PIPEDA_Law25_Mapping.csv) — Mapping matrix that ties core NIST CSF functions and subcategories to PIPEDA and Quebec Law 25 obligations, with suggested controls.
